Ztlumená slova a témata

Zprávy, jejichž titulek nebo perex obsahuje některé z těchto slov, se skryjí. Jedno slovo nebo fráze na řádek, velikost písmen a diakritika nehrají roli. Slova do 3 znaků se hledají jako celá slova.

Zvýrazněná slova

Vlastní RSS / Atom kanály

Přidejte libovolný kanál. Prohlížeč ho stahuje sám, takže to funguje jen u webů, které čtení z cizí stránky povolují (CORS), nebo přes vaši proxy níže. Vlastní kanály vidíte jen vy.

Proxy pro kanály bez CORS

Šablona adresy, {url} se nahradí zakódovanou adresou kanálu. Prázdné = bez proxy. Veřejné proxy neznámých provozovatelů nepoužívejte – vidí vše, co přes ně jde. Vlastní proxy zdarma: Cloudflare Workers.

Kód Cloudflare Workeru (zkopírovat do nového Workeru) 
export default {
  async fetch(req) {
    const cil = new URL(req.url).searchParams.get('url');
    if (!cil || !/^https?:\/\//.test(cil)) return new Response('?url=', { status: 400 });
    const r = await fetch(cil, { headers: { 'User-Agent': 'Mozilla/5.0 RSS' } });
    const h = new Headers(r.headers);
    h.set('Access-Control-Allow-Origin', '*');
    return new Response(r.body, { status: r.status, headers: h });
  }
};

Automatická obnova

Weby se stahují centrálně každých 20 minut (GitHub Actions) a stránka si hotový přehled jen načte – nezatěžuje tím zpravodajské weby ani vaše připojení. Poslední data zůstávají v prohlížeči i pro čtení offline.

Stav webů při posledním stažení

Přenos do jiného zařízení

Nastavení, uložené a přečtené články zůstávají jen v tomto prohlížeči. Přenesete je kódem, souborem nebo QR kódem – nic se neposílá na server.

📲 Aplikace na ploše

Na telefonu: v prohlížeči nabídka ⋮ → „Přidat na plochu“ (Android), v Safari Sdílet → „Přidat na plochu“ (iPhone). Otevře se jako aplikace a uložené zprávy jdou číst i bez připojení.

Uložená data

Mozaika skládá titulky z vybraných zpravodajských webů do jednoho přehledu seřazeného podle času. Klik na dlaždici ukáže náhled s anotací, teprve tlačítko „Číst na …“ (nebo klik na titulek či obrázek) otevře článek na webu, který ho napsal. Ctrl+klik nebo prostřední tlačítko otevře web rovnou. Když o stejné události píše víc webů, spojí se do tématu – dlaždice má štítek „+N“ a náhled ukáže, jak o tom píší ostatní.

Režimy: 📰 Zprávy ukazují všechno včetně politiky, 🌙 Zajímavosti jen vědu, techniku, hry, přírodu, kulturu… a skrývají politiku a válku i v ostatních rubrikách (třeba na večer před spaním). Každý režim má vlastní výběr v tlačítku 🗂️ Rubriky.

Večer: od 21:00 se stránka sama přepne na 🌙 Zajímavosti – bez politiky, neštěstí a s tlumenými barvami; ráno zpět (nastavení → 🌙 Večer). Po delší nepřítomnosti ukáže nahoře „co jste zmeškali“. V náhledu zprávy je 🧵 vývoj tématu od první zprávy po nejnovější.

Sledovaná témata: zvýrazněná slova (Nastavení → Filtry) mají v 🗂️ Rubriky vlastní pohled 📌 – všechny zprávy o tématu i ze starších dnů. Můj kraj: regionální zprávy z vybraného kraje (Nastavení → Jazyky a kraj). Kopie téhož článku od jednoho vydavatele (iDNES + Lidovky) se počítají jako jedna redakce.

Obnova: všechny weby se stahují centrálně každých 20 minut. Tlačítko ⟳ navíc hned načte živě ty weby, které to prohlížeči dovolují (iDNES, ČT24, iROZHLAS, NYT…), a ostatní přes vaši proxy, pokud ji máte nastavenou. Hledání otevře lupa 🔍 nebo klávesa /.

Které weby sledujete, nastavíte v ⚙️ Nastavení → Weby. Výběr, přečtené a uložené články zůstávají jen ve vašem prohlížeči.
